readme = r'''# PathBack PWA

PathBack is a browser-based Progressive Web App that records a user’s walking path as a live breadcrumb trail and helps the user return to the original starting point. The project was inspired by a common indoor navigation problem: entering a large place like a shopping mall from one entrance, walking through multiple turns and floors, then forgetting the original way back.

This app is designed as a fun but useful indoor path memory tool. It does not track other people. It only records the user’s own journey after the user manually starts a session.
